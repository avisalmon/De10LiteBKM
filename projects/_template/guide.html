What you need

  • FILL IN: the board, the shield or not, wires or sensors.
  • Quartus Prime Lite 17.1 installed as in stage 1 of the BKM (python scripts/doctor.py shows no FAIL).

Build and load it

python scripts/de10.py build   projects/FILL IN name      # a few minutes; ends with the resource and timing summary
python scripts/de10.py program projects/FILL IN name      # loads it over the USB-Blaster; runs until power-off

From the archive instead: Quartus Project → Restore Archived Project → FILL IN name.qar, compile, program.

Test over USB

python scripts/de10.py send "?"      # the debug link's status line

Keep it after power-off

python scripts/de10.py flash projects/FILL IN name        # writes and verifies the .pof, about 15 s

It replaces whatever was in the flash before (the chat asks first).
