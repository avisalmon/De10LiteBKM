Projects

Whole designs, not single capabilities: each one was built by the AI from the BKM's examples and skills, reviewed, tested in simulation and on the board, and documented the same way: an overview with the block diagram and the flow, an architecture spec, a user guide, and the full Quartus project as a .qar.

Space Invaders

The 1978 arcade game in pure Verilog, with no CPU and no frame buffer: one game step per frame inside the vertical blank (at most 1,351 of its 28,000 clocks), then every pixel worked out as the screen scans it. The rules from the arcade's disassembly and MAME, our own pictures at the arcade's sizes. All 10 test presets matched the simulation pixel for pixel on the board. 7,170 logic elements.

Runs on the boardFlashed, verified by the programmer

Still to check by hand: the game pad, the status LED, the LEDs and digits, KEY0, KEY1 and the switches, a wave played by hand, the start after a power cycle, a photo.

Accelerometer Cube

The on-board ADXL345 read over SPI; a shaded 3D cube that tilts with the board, drawn with no frame buffer (one math engine in the blanking, a 4-stage pixel pipeline), beside the live acceleration as text, bars and a 3D arrow. All 8 presets matched a bit-exact Python model pixel by pixel; the tilt directions and the A-button calibration checked by hand. 13,238 logic elements.

Runs on the boardStarts from the flash at power-up

Still to check by hand: B, Select and Start on the game pad; the LED bubble, fixed, to be watched once more; a photo.

FFT Lab

A wave generator, a scope and two 256-point FFTs on the same samples: our own radix-2 RTL (6,145 clocks) beside Altera's FFT II IP (1,637). Every pixel matched a bit-exact Python model. A tutorial of ten experiments comes with it. 7,183 logic elements.

Runs on the boardEvaluation IP: the PC stays connected

Still to check by hand: the wheel, joystick, buttons and keys (the USB letters are verified); the buzzer; the LEDs and the 7-segment display.

RISC-V Tetris

A RISC-V CPU in Verilog, 32 KB RAM, an 80x60 text screen; a Python assembler, C compiler and simulator; Tetris in C on it. The RTL matched the simulator over 294,803 steps. 10,658 logic elements.

Runs on the board

Still to check by hand: the joystick's feel, the sounds, the pace.

Pac-Man

The arcade game: the real maze, four ghosts with the arcade AI, power pellets, levels, lives, the intro tune. 9,504 logic elements.

Runs on the board

Still to check by hand: playing with the joystick (USB play is verified), the sounds, the start after a power cycle once flashed.

What every project folder holds

FileWhat it is
index.htmlthe overview: what it does, what you will see, the block diagram, how it flows, how it was tested, the review log, status, files
spec.htmlthe architecture spec: requirements, modules and ports, clock domains, memories, state encodings, budgets, design decisions
guide.htmlthe user guide: build, load, use, test over USB, flash, simulate, change, troubleshoot
tutorial.htmloptional: experiments to try on the board, each with what you should see and why
<name>.qarthe whole Quartus project, archived by Quartus itself
src/, sim/, assets/, media/the sources, the testbench, generated data and generators, the pictures

No bitstreams in the repo: one build (a few minutes) makes the .sof. The standard is the make-project skill, with a template in projects/_template/; a test checks that every project has these files and that this page links it. For single capabilities (a PLL, a ROM, the SDRAM...) see the examples.
