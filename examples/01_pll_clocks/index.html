01 · PLL and clocks

Make any clock you need from the board's 50 MHz oscillator, and prove it: the design measures every clock it has and shows the result on the 7-segment display and on your PC.

How the PLL is set

The PLL is the reusable lib/rtl/pll_de10.v: a direct instance of Altera's altpll (the same thing the IP wizard writes) with each output set by three parameters:

pll_de10 #(
  .C0_MUL(1), .C0_DIV(2),                      // 50 * 1/2 = 25 MHz
  .C1_MUL(2), .C1_DIV(1),                      // 100 MHz
  .C2_MUL(2), .C2_DIV(3),                      // 33.333 MHz
  .C3_MUL(1), .C3_DIV(5),                      // 10 MHz
  .C4_MUL(1), .C4_DIV(1), .C4_PHASE("5000")    // 50 MHz, 5000 ps = 90 degrees late
) pll (.areset(~KEY[0]), .inclk0(MAX10_CLK1_50), .clk(pll_clk), .locked(locked));

Rule: fout = 50 MHz × MUL / DIV. Quartus finds a VCO frequency and counter values that make all five outputs at once; if it can't, the build stops with an error naming the clock. What it actually built is in output_files/pll_clocks.fit.rpt, section PLL Usage. For this example:

OutputMUL/DIVFrequencyPhaseCounter (from VCO 600 MHz)
c01/225.0 MHz0C0 = 24
c12/1100.0 MHz0C1 = 6
c22/333.33 MHz0C2 = 18
c31/510.0 MHz0C3 = 60
c41/150.0 MHz90° (5000 ps)C4 = 12

The VCO runs at 50 × M / N = 50 × 12 / 1 = 600 MHz, and each output divides it by its counter. Phase steps come in VCO steps of 208 ps, so a phase that is not a multiple of 208 ps is rounded (the report shows the value used).

Things to know

  • Use locked. PLL outputs are not stable until locked is high. Hold your logic in reset until then; this example shows it on LEDR9.
  • Each clock is its own world. A signal that crosses from one clock to another must go through a synchronizer. freq_counter shows the safe pattern: a 1-bit gate crosses through two flip-flops, and the multi-bit count is read only while it is standing still.
  • Tell the timing analyzer. The .sdc file has create_clock for the oscillator and derive_pll_clocks, so every PLL output is checked automatically. This example meets timing with no negative slack.
  • The DE10-Lite has three oscillators: MAX10_CLK1_50 and MAX10_CLK2_50 (50 MHz each) and ADC_CLK_10 (10 MHz). The MAX 10 has 4 PLLs; one is enough here.

Run it

Just the result

python scripts/de10.py program examples/01_pll_clocks/pll_clocks.sof
python scripts/de10.py log 3

Or open Quartus Prime Programmer, choose USB-Blaster, add pll_clocks.sof, tick Program/Configure, Start.

Build it yourself

python scripts/new_project.py examples/01_pll_clocks pll_clocks_top --lib pll print bcd freq sevenseg
python scripts/de10.py build examples/01_pll_clocks
python scripts/de10.py program examples/01_pll_clocks

Or restore pll_clocks.qar in Quartus (Project → Restore Archived Project); it holds the project and the library files it uses, in their folders.

Test without the board

python scripts/sim.py examples/01_pll_clocks/sim/tb_freq_counter.sv              # Icarus Verilog
python scripts/sim.py examples/01_pll_clocks/sim/tb_freq_counter.sv --modelsim   # ModelSim
→ 25 MHz -> 25000 kHz, 10 MHz -> 10000 kHz   PASS

This test caught a real bug while the example was being made: the first version lost one edge per gate and showed 24999.
